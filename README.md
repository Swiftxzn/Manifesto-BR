# 🇧🇷 Manifesto-BR

O **Manifesto-BR** é uma iniciativa de código aberto dedicada a mapear, catalogar e estruturar dados de sites da internet brasileira.
---

## 🎯 Objetivo do Projeto

Fornecer uma base de dados padronizada, atualizada e de fácil consumo sobre o ecossistema de sites nacionais (`.br`), permitindo que desenvolvedores e analistas utilizem essas informações em ferramentas de inteligência, segurança da informação ou pesquisa digital.

---

## 🚀 Como Utilizar

Você pode clonar este repositório ou consumir o arquivo JSON diretamente em seus scripts (Python, JavaScript, Go, etc.).

### 1. Clonando o Repositório

```bash
git clone https://github.com/Swiftxzn/Manifesto-BR
cd Manifesto-BR
```

## RECOMENDO USAR COM SHERLOCK BY Nwokike

```
https://github.com/Swiftxzn/Sherlock
```

### 2. Consumindo o JSON via URL Direta (Raw)

Se você precisa carregar os dados em tempo de execução na sua aplicação, utilize o link direto do GitHub:

Oficial Maifret:
```text
https://raw.githubusercontent.com/Swiftxzn/Manifesto-BR/refs/heads/main/data-oficial-maigret.json
```
Oficial Br:
```text
https://raw.githubusercontent.com/Swiftxzn/Manifesto-BR/refs/heads/main/data-br-manual-semIA.json
```

## 🛠️ Contribuição

Contribuições são muito bem-vindas! Se você encontrou um erro, quer sugerir novos sites ou melhorar a estrutura do JSON:

1. Faça um **Fork** do projeto.
2. Crie uma **Branch** para sua modificação (`git checkout -b feature/nova-lista`).
3. Faça o **Commit** das suas alterações (`git commit -m 'Adiciona novos sites BR'`).
4. Envie para o repositório remoto (`git push origin feature/nova-lista`).
5. Abra um **Pull Request**.
